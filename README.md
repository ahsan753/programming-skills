# Programming Skills

An interactive site to learn, practise and apply every Cambridge IGCSE Computer Science (0984) programming skill.

It covers **Skills 1–13** across two worlds:

- **World A: Core building blocks** – Skills 1–7 (variables, data types, input/output, sequence, operators)
- **World B: Control structures** – Skills 8–13 (selection, loops, nesting)

Python runs right in your browser, so there's nothing to install.

**Open the site:** https://ahsan753.github.io/programming-skills/
